# Talal Malik - personal website

A plain HTML/CSS site for GitHub Pages. No build step needed.

## Publish
1. Create a public repo named exactly `talalmalickk.github.io` (must match your GitHub username).
2. Unzip this folder on your computer. Open the unzipped folder, select ALL its contents
   (index.html, the other .html files, the assets folder, README.md) and drag them into
   the repo page: Add file -> Upload files. Click Commit changes.
3. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
4. Wait 1-3 minutes, then open https://talalmalickk.github.io

## Change your photo
Replace `assets/img/profile.jpg` with a new image with the SAME file name
(profile.jpg). On GitHub: open assets/img, Add file -> Upload files. Uploading a file with
the same name replaces the old one.

## Change your CV
Replace `assets/Talal_Malik_CV.pdf` the same way (keep the same file name).

## Edit text
Open the page (e.g. experience.html) on GitHub, click the pencil icon, edit the text
between the HTML tags, then Commit changes.

## Change the accent color
Open assets/css/style.css and edit `--accent` at the top (light mode) and in the
[data-theme="dark"] block (dark mode).
